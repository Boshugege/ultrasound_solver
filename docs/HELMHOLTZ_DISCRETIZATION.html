Helmholtz Equation Discretization

本文档说明当前代码如何把连续声学 Helmholtz 方程离散成线性方程组：

从流体力学到矩阵组装的完整推导见 ACOUSTIC_PHYSICS_DERIVATION.html；边界凝聚推导见 BOUNDARY_CONDENSATION.html；纯相位训练见 PHASE_ONLY_TRAINING.html；三种求解后端见 SOLVER_ARCHITECTURE.html。

\[ A u = b \]

对应实现主要位于 warp_utils.py 的 assemble_helmholtz_kernel。

连续方程

当前离散对应的变参数频域声学方程可写成：

\[ \nabla \cdot \left(\frac{1}{\rho(\mathbf{x})}\nabla u(\mathbf{x})\right) + \frac{\omega^2}{\rho(\mathbf{x})c(\mathbf{x})^2}u(\mathbf{x}) = f(\mathbf{x}) \]

其中：

符号 含义
\(u(\mathbf{x})\) 复声压场
\(\rho(\mathbf{x})\) 空间变密度
\(c(\mathbf{x})\) 空间变声速
\(\omega = 2\pi f\) 角频率
\(f(\mathbf{x})\) 外部源项或由边界激励等效形成的右端

在当前实现中，内部普通网格点没有体源项，因此右端通常为 0。 换能器通过底面刚性挡板上的 sinc Neumann 孔径通量写入右端，见 SINC_NEUMANN_SOURCE.html。

网格与编号

计算域使用等间距 3D 直角网格：

\[ x_i = i\Delta x,\qquad y_j = j\Delta x,\qquad z_k = k\Delta x \]

当前求解器要求各向同性网格：

\[ \Delta x = \Delta y = \Delta z \]

三维网格点 \((i,j,k)\) 被展平成一维自由度编号：

\[ p(i,j,k) = i + jN_x + kN_xN_y \]

代码中对应：

idx = i + j * nx + k * (nx * ny)

介质参数离散

每个网格点保存局部密度和声速：

\[ \rho_{i,j,k} = \rho(x_i,y_j,z_k) \] \[ c_{i,j,k} = c(x_i,y_j,z_k) \]

代码中通过 SDF 和 smooth Heaviside 在背景介质与障碍物介质之间平滑过渡：

\[ \rho = \rho_{\mathrm{obs}} + (\rho_0 - \rho_{\mathrm{obs}})H(\phi) \] \[ c = c_{\mathrm{obs}} + (c_0 - c_{\mathrm{obs}})H(\phi) \]

其中 \(\phi\) 是 SDF 值，\(H(\phi)\) 是平滑 Heaviside 函数。

内部点 7 点 stencil

对于非换能器、非开放边界的普通点，代码使用 7 点有限差分 stencil。

记当前点为：

\[ P = (i,j,k) \]

当前点密度为：

\[ \rho_P = \rho_{i,j,k} \]

相邻点 \(Q\) 与当前点 \(P\) 的面系数定义为：

\[ a_{P,Q} = \frac{1}{\Delta x^2} \frac{2}{\rho_P + \rho_Q} \]

这相当于在半网格面上使用 \(1/\rho\) 的调和型平均。

质量项为：

\[ m_P = \frac{\omega^2}{\rho_P c_P^2} \]

代码中的矩阵行为：

\[ A_{P,Q} = a_{P,Q} \qquad Q \in \mathcal{N}(P) \] \[ A_{P,P} = m_P - \sum_{Q \in \mathcal{N}(P)} a_{P,Q} \]

因此普通内部点的离散方程为：

\[ \left( m_P - \sum_{Q \in \mathcal{N}(P)} a_{P,Q} \right)u_P + \sum_{Q \in \mathcal{N}(P)} a_{P,Q}u_Q = 0 \]

其中 \(\mathcal{N}(P)\) 是当前点存在的六个轴向邻居集合。

Reflecting 边界

reflecting 边界在当前代码中不是单独替换为一条边界方程，而是通过 stencil 的缺失邻居处理实现。

如果某个方向越界，代码不会加入该方向的邻居项，也不会把该方向的通量加入对角线求和。

例如在 \(-x\) 反射边界上，若 \(i=0\)，则不存在 \(i-1\) 邻居：

\[ a_{P,P-\hat{x}} = 0 \]

这等价于该边界方向的离散零法向通量近似：

\[ \frac{\partial u}{\partial n} = 0 \]

因此 reflecting 边界通过“缺失外侧通量”进入矩阵。

Open 边界

open 边界使用局部一阶 Sommerfeld 条件：

\[ \frac{\partial u}{\partial n} - i\frac{\omega}{c_P}u = 0 \]

除以密度后，外向通量为 \((1/\rho_P)\partial u/\partial n=i\omega u/(\rho_Pc_P)\)。 若该控制体积外表面面积权重为 \(S_f\)、体积权重为 \(V_P\)，则在原 PDE 对角项增加：

\[ \Delta A_{P,P}^{\mathrm{open}} = \frac{i\omega S_f}{\rho_Pc_PV_P} \]

原有内部邻居和质量项保持不变；多个 open/impedance 面在棱角处逐面累加。 生产配置还会在 open 面内侧使用坐标拉伸 PML。

换能器 sinc Neumann 通量

底面 \(z=0\) 整体按 reflecting 刚性挡板装配。设第 \(j\) 个阵元中心为 \(\mathbf c_j\)，孔径点 \(\mathbf s\) 的局部径向坐标为 \(\varrho_j(\mathbf s)=\|\mathbf s_\parallel-\mathbf c_j\|\)。 在 \(\varrho_j(\mathbf s)<a\) 内施加：

\[ \frac{1}{\rho}\frac{\partial u}{\partial n} = \frac{2\pi}{\rho_{\mathrm{ref}}} A_je^{i\phi_j} \frac{1}{2\pi a\sqrt{a^2-\varrho_j(\mathbf s)^2}} \]

求积和双线性沉积得到单位质量矩阵 \(M_s\)，底面外法向为 \(-z\)， 因而离散源列为：

\[ S_{\mathrm{bottom}} = -\frac{2\pi}{\rho_{\mathrm{ref}}\Delta x^3}M_s \]

令 \(B=S\,\mathrm{diag}(A_1,\ldots,A_M)\)，完整 RHS 为：

\[ b(\phi)=B e^{i\phi} \]

声源不替换矩阵行；底面压力仍由 Helmholtz 方程求解。

最终线性系统

对所有网格点重复上述规则后，每个点 \(P\) 对应矩阵的一行。

点类型 矩阵行来源 右端来源
内部点 变参数 7 点 Helmholtz stencil 0
reflecting 边界点 缺失外侧通量的 stencil 0
open 边界点 保守 PDE 行 + 局部 Sommerfeld 面通量 0
换能器点 reflecting 控制体积行 sinc Neumann 积分通量

最终得到复数稀疏线性系统：

\[ A u = b \]

所有后端都只对这个已经装配好的 \(A\) 和 \(b\) 做代数运算，因此严格继承所有边界条件和换能器激励。

边界行的精确静态凝聚

本节给出摘要，完整块分解证明、稀疏传递矩阵和同因子伴随推导见 BOUNDARY_CONDENSATION.html。

边界凝聚仅处理确实可以消元的边界自由度；sinc Neumann 源属于保守 RHS， 不产生待消去的换能器 Dirichlet 行。把保留自由度记为 \(R\)， 待消去边界自由度记为 \(E\)，原方程写为：

\[ \begin{bmatrix} A_{RR} & A_{RE} \\ A_{ER} & A_{EE} \end{bmatrix} \begin{bmatrix} u_R \\ u_E \end{bmatrix} = \begin{bmatrix} b_R \\ b_E \end{bmatrix} \]

对第二行做精确代数消元：

\[ u_E = A_{EE}^{-1}(b_E-A_{ER}u_R) \]

得到约化方程：

\[ \left( A_{RR}-A_{RE}A_{EE}^{-1}A_{ER} \right)u_R = b_R-A_{RE}A_{EE}^{-1}b_E \]

当前 Robin/Neumann 自然边界保留在保守 PDE 矩阵中，不按旧式两元素边界行消元。 仅满足规定值结构的自由度进入 \(E\)。约化矩阵必须通过复对称检查； 求得 \(u_R\) 后再恢复 \(u_E\)，最终返回原始 \(A u=b\) 的完整空间解。

相位更新时的矩阵复用

当前优化变量只有换能器相位。介质、障碍物、频率、网格和边界条件不变时， 矩阵 \(A\) 不随相位变化，只有通量源右端变化：

\[ b(\phi) = B e^{i\phi} \]

因此第一次调用会装配 \(A\)、缓存稀疏孔径源列并建立求解因子； 后续相位迭代使用 complex128 更新复数 RHS：

\[ b(\phi)=B\left(A\odot e^{i\phi}\right) \]

这不是近似或边界修改，只是避免重复计算与相位无关的矩阵条目。 首次完整装配和 RHS-only 更新使用同一有限孔径质量矩阵。
