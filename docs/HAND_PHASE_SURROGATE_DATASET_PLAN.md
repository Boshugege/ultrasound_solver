# 固定手模型关节姿态到 256 通道相位的数据集设计

详细的数据获取、训练集生成和评测集冻结流程见：

```text
docs/HAND_PHASE_SURROGATE_DATA_COLLECTION.md
```

## 1. 目标与结论

目标是训练一个固定手模型的代理网络：

\[
f(\text{手根位姿},\text{关节姿态},\text{目标点})
\rightarrow
\text{256 通道聚焦相位}
\]

该任务成立的前提是：

- 手的形状、骨长、网格拓扑和蒙皮权重固定；
- 变化只来自手根 6DoF、关节姿态和目标点；
- 阵列几何、频率、空气参数和刚性底板固定；
- 手仍按封闭刚性表面建模；
- 训练和部署使用同一通道顺序。

网络只需逼近一个有限维、确定性的映射。固定手模型会显著降低问题难度，但模型只对该手型和训练工作空间负责。

## 2. 当前前置条件

当前文件：

```text
obstacle_displacement_study/models/hand_watertight.vtk
```

是静态闭合网格，仓库中没有对应的：

- 骨骼层级；
- 关节自由度定义；
- 蒙皮权重；
- 关节限位；
- 自碰撞检测。

因此不能直接从“关节角”生成形变后的 BEM 表面。

### 推荐方案

为当前固定网格增加一次性的 21 关节骨架和蒙皮权重：

```text
hand_rig/
  template_vertices.npy
  faces.npy
  joint_rest_positions.npy
  joint_parents.npy
  skinning_weights.npy
  joint_limits.yaml
  rig_manifest.json
```

使用线性混合蒙皮或双四元数蒙皮生成形变网格，始终保持相同顶点数、面元连接关系和面元顺序。

选择当前网格而不是直接更换 MANO 网格，是为了继承已完成的手部 BEM 网格收敛与性能证据。若采用 MANO，应将其视为新的固定手模型，重新进行网格收敛验证。

## 3. 输入参数化

数据生成时保存两套等价输入，便于后续消融。

### 3.1 生成用参数

```text
root_translation_m     [3]
root_rotation_6d       [6]
joint_angles_rad       [J]
target_world_m         [3]
```

- 根旋转使用连续 6D 表示，不使用存在符号跳变的四元数监督；
- 关节角使用解剖约束下的低维自由度；
- 目标点使用阵列世界坐标。

第一版建议约 20–26 个关节自由度，包括：

- 四指 MCP 屈伸和外展；
- 四指 PIP、DIP 屈伸；
- 拇指 CMC 双自由度；
- 拇指 MCP、IP 屈伸；
- 可选腕关节屈伸和侧偏。

### 3.2 网络候选输入

同时保存：

```text
joint_positions_world_m [21, 3]
target_hand_local_m     [3]
```

后续比较两种输入：

1. `root pose + joint angles + target`：维度低，与生成模型一致；
2. `21 joint positions + target`：更容易直接对接视觉手部跟踪器。

固定手型下，21 个关节点能够描述大部分姿态，但不能完整表达骨骼扭转，因此正式模型优先使用关节旋转参数，关节点输入作为视觉接口基线。

## 4. 输出与标签规范

### 4.1 不只保存相位

教师 BEM 对每个目标输出 256 通道复响应：

\[
\mathbf h=(h_1,\ldots,h_{256})
\]

相位标签为：

\[
\phi_j^\star=-\arg h_j
\]

数据集必须保存原始复响应，而不是只保存相位：

```text
response_real          [256] float32
response_imag          [256] float32
```

原因：

- 可按 \(|h_j|\) 降低低能量通道的相位权重；
- 可直接计算严格的聚焦效率；
- 可重新生成连续相位和 32 档相位；
- 后续可以训练“复响应代理模型”，而不必重新生成数据。

### 4.2 相位的全局不唯一性

所有通道同时增加相同相位，不改变单点聚焦幅值：

\[
\phi_j^\star\rightarrow\phi_j^\star+\phi_0
\]

因此不应直接对 256 个弧度使用普通 MSE。

推荐网络输出 256 个二维向量：

\[
(\hat c_j,\hat s_j)\approx(\cos\phi_j,\sin\phi_j)
\]

归一化为单位复数：

\[
\hat z_j=
\frac{\hat c_j+i\hat s_j}
{\sqrt{\hat c_j^2+\hat s_j^2+\epsilon}}
\]

训练使用全局相位不变、按通道响应幅值加权的相关损失：

\[
L_{\mathrm{phase}}
=
1-
\frac{\left|\sum_j w_j\hat z_jz_j^\ast\right|}
{\sum_jw_j},
\qquad
w_j=|h_j|
\]

还应直接加入教师响应下的聚焦损失：

\[
L_{\mathrm{focus}}
=
1-
\frac{\left|\sum_jh_j\hat z_j\right|}
{\sum_j|h_j|}
\]

最终损失建议：

\[
L=L_{\mathrm{focus}}+\lambda L_{\mathrm{phase}}
\]

部署时再把连续相位量化到 32 档。

## 5. 姿态采样设计

不能独立均匀采样每个关节，否则会产生大量不自然或自相交的手势。建议按混合分布采样。

| 姿态来源 | 占训练姿态 | 内容 |
|---|---:|---|
| 受限 Sobol 关节采样 | 40% | 覆盖各关节范围，加入 DIP/PIP 等相关约束 |
| 手势模板扰动 | 25% | 张手、握拳、指向、捏合、三指捏、钩形、侧捏 |
| 手部协同空间 | 20% | 用真实或动画手姿态 PCA/协同量采样自然关节组合 |
| 连续轨迹 | 10% | 在两种手势间插值，覆盖动态路径 |
| 关节边界压力测试 | 5% | 接近关节限位，但必须通过网格质量检查 |

### 手根位姿

以当前验证姿态为中心：

```yaml
center_m: [0.08, 0.082, 0.1165]
rotation_deg: [0, 90, 90]
```

第一版训练范围建议：

- 横向平移：标称位置附近 ±20 mm；
- 高度平移：标称位置附近 ±20 mm；
- yaw：±30°；
- pitch/roll：±20°。

最终不只依赖参数范围，还必须满足：

- 网格最低点与挡板至少保持安全距离；
- 网格不穿过阵列底板；
- 网格没有退化面元和明显自相交；
- 手和目标都在经过验证的阵列工作空间内。

## 6. 目标点采样

每个手姿态装配一次 BEM 矩阵，然后复用该矩阵生成多个目标点标签。这样可以把最昂贵的形变矩阵装配成本摊薄。

每个姿态建议生成 32 个目标：

| 目标类别 | 每姿态数量 | 采样方式 |
|---|---:|---|
| 掌面附近 | 12 | 阵列侧掌面法向外偏移 5–20 mm |
| 指腹/指尖附近 | 10 | 每指选择代表表面点，向空气侧偏移 3–15 mm |
| 关节和遮挡困难点 | 6 | 指缝、指节附近、声影较强区域 |
| 工作空间均匀点 | 4 | 阵列上方合法空间内均匀采样 |

所有目标必须满足：

- 不在手网格内部；
- 距手表面大于教师积分的安全下限；
- 高于刚性挡板；
- 不落在换能器孔径奇异位置；
- 单焦点理论上限 \(\sum_j|h_j|\) 不低于最低可用阈值。

同时保存目标类别，便于分组评估。

## 7. 教师 BEM 设置

### 7.1 Pilot 教师

用于快速验证数据管线：

```text
surface resolution: lambda/4
matrix: complex64
GMRES rtol: 1e-5
scattered aperture quadrature: 8 x 32
```

### 7.2 正式教师

建议最终标签使用：

```text
surface resolution: lambda/5
matrix: complex64
GMRES rtol: 1e-6 或经消融确认的 1e-5
fine aperture quadrature
```

并随机抽取至少 1% 样本，与更细网格或更严格残差交叉验证。实时 FP16、`rtol=1e-2` 的 31 ms 路径不应直接作为最终训练真值。

### 7.3 生成过程

对每个姿态：

1. 根据关节参数生成形变后的闭合网格；
2. 检查法向、面元质量、自相交和挡板距离；
3. 完整装配一次 BEM 矩阵；
4. 对该姿态的 32 个目标逐个使用互易性求 256 通道响应；
5. 保存复响应、残差、耗时和精度元数据；
6. 释放或复用矩阵，不保存稠密矩阵本身。

## 8. 数据规模

建议分三阶段。

| 阶段 | 手姿态 | 每姿态目标 | 样本对 | 复响应标签体积 |
|---|---:|---:|---:|---:|
| 管线验证 | 200 | 16 | 3,200 | 约 6.6 MB |
| MVP | 5,000 | 32 | 160,000 | 约 328 MB |
| 正式版 | 20,000 | 32 | 640,000 | 约 1.31 GB |

标签体积按 256 通道 complex64 计算，不含压缩和元数据。

RTX 4090 上正式版预计是数小时到十余小时量级，但必须先用 200 姿态 Pilot 实测：

- 完整形变矩阵装配时间；
- 单目标严格求解时间；
- 每姿态 32 目标的矩阵复用收益；
- 峰值显存；
- 无效姿态拒绝率。

在没有 Pilot 数据前，不承诺完整生成时长。

## 9. 数据划分

必须以“完整姿态或完整轨迹”为单位划分，不能把同一姿态下的不同目标随机分到训练和测试。

正式版 20,000 姿态建议：

| 划分 | 姿态数 | 用途 |
|---|---:|---|
| Train | 14,000 | 网络训练 |
| Validation | 2,000 | 模型与超参数选择 |
| Test-ID | 2,000 | 训练分布内独立测试 |
| Test-OOD | 2,000 | 未见手势组合、边界姿态和扩大工作空间 |

额外要求：

- 连续轨迹的所有帧必须进入同一个 split；
- OOD 测试保留至少一种完整手势类别不参与训练；
- 近邻姿态聚类后按簇划分，避免几乎相同的姿态跨 split；
- 目标类别比例在 ID 划分中保持一致；
- 随机种子和姿态 ID 固定并写入 manifest。

## 10. 数据格式

建议使用分片 NPZ，避免单个超大文件，也与当前仓库工具链一致。

```text
outputs/hand_phase_dataset_v1/
  manifest.json
  rig_manifest.json
  splits.json
  poses/
    poses_000.npz
    ...
  responses/
    train_000.npz
    validation_000.npz
    test_id_000.npz
    test_ood_000.npz
  audit/
    rejected_poses.jsonl
    convergence_summary.json
    refinement_checks.json
```

姿态表：

```text
pose_id                  int64
root_translation_m       float32 [P,3]
root_rotation_6d         float32 [P,6]
joint_angles_rad         float32 [P,J]
joint_positions_world_m  float32 [P,21,3]
gesture_family           uint8   [P]
split                    uint8   [P]
```

响应分片：

```text
sample_id                int64
pose_id                  int64
target_world_m           float32 [N,3]
target_hand_local_m      float32 [N,3]
target_category          uint8   [N]
response_real            float32 [N,256]
response_imag            float32 [N,256]
gmres_residual           float32 [N]
solve_ms                 float32 [N]
focus_upper_bound        float32 [N]
```

不保存每个姿态的稠密 BEM 矩阵。相位、单位复数和 32 档相位码由复响应确定性生成，避免冗余标签失配。

## 11. 质量门槛

### 几何门槛

- 闭合、流形、法向朝外；
- 面元连接关系与模板一致；
- 无退化三角形；
- 无明显自相交；
- 手不穿过底板；
- 目标不在手内部。

### 数值门槛

- GMRES 明确收敛；
- 相对残差不超过教师阈值；
- 所有复响应有限；
- 低能量通道比例在可接受范围；
- 随机 1% 样本通过网格/残差加密复核；
- 连续相位和 32 档相位均计算教师模型中的聚焦效率。

### 数据审计

- 保存 rig、网格、求解器代码和配置 SHA-256；
- 保存 Git commit；
- 保存 GPU、CUDA、CuPy 版本；
- 保存每种姿态来源和目标类别的数量；
- 所有拒绝样本保留原因，不能静默跳过。

## 12. 网络验收指标

主指标不是逐通道相位 MSE，而是教师复响应下的聚焦效率：

\[
\eta=
\frac{\left|\sum_jh_j e^{i\hat\phi_j}\right|}
{\sum_j|h_j|}
\]

至少报告：

| 指标 | 分组 |
|---|---|
| 连续相位聚焦效率的均值/P5/最差值 | ID、OOD、各手势、各目标类别 |
| 32 档量化后聚焦效率 | 同上 |
| 按 \(|h_j|\) 加权的循环相位误差 | 同上 |
| 推理延迟中位/P95 | GPU、CPU |
| 低置信度或回退率 | ID、OOD |
| 相对数值 BEM 的端到端加速比 | 含输入预处理与量化 |

第一版建议验收门槛：

- Test-ID 连续相位 P5 聚焦效率 ≥ 99.5%；
- Test-ID 32 档相位 P5 ≥ 99.0%；
- OOD 必须单独报告，不以 ID 指标代替；
- 超出关节范围、目标工作空间或置信度门槛时回退数值 BEM 或关闭输出。

## 13. 防止过拟合与部署安全

固定手模型可以降低学习难度，但也容易让随机划分产生虚高结果。必须：

- 按姿态簇和轨迹划分；
- 保留完整未见手势测试；
- 使用独立、更精细 BEM 教师进行测试；
- 不根据测试集修改关节范围和目标分布；
- 报告最差值和低分位，而不只报告均值。

直接相位网络没有类似线性残差的廉价物理门控。部署时至少加入：

- 输入关节范围检查；
- 网格碰撞和挡板距离检查；
- 目标合法性检查；
- 训练分布距离或模型不确定度；
- 超阈值时回退 BEM；
- 跟踪丢失时立即发送 `off`。

## 16. 核心决策

1. 固定的是手的形状和拓扑，不是手的姿态。
2. 一个姿态装配一次矩阵，复用到 32 个目标点。
3. 数据集保存完整复响应，不只保存相位。
4. 相位训练使用全局相位不变损失，不直接回归弧度 MSE。
5. 按姿态和轨迹划分数据，不能按目标点随机划分。
6. 最终评价以数值 BEM 中的聚焦效率为准。
7. 网络不确定时必须回退 BEM 或关闭硬件输出。
