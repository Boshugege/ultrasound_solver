Mesh to SDF 使用说明

当前 mesh-to-SDF 不是单独的命令行工具，而是通过 YAML 配置中的 obstacles 自动触发。只要障碍物类型设为 mesh，求解器在装配矩阵前会调用 src/algorithm/physics/mesh_to_sdf.py，把闭合三角网格采样为与求解域同分辨率的 SDF。

基本流程

  1. 准备一个闭合、流形的表面 mesh 文件。
  2. 在 YAML 的 obstacles 中配置 type: "mesh"。
  3. 运行 python src/main.py --config ...。
  4. 求解器自动读取 mesh、执行变换、采样 SDF、生成材料场，并参与 Helmholtz 矩阵装配。

入口调用链为：

SimulationConfig.from_yaml()
  -> 解析 mesh 文件路径
HelmholtzDirectSolver.assemble_matrix()
  -> mesh_to_sdf(...)
WarpAssemblyEngine.assemble_system_gpu()
  -> compute_material_fields_sdf_kernel(...)

YAML 配置示例

obstacles:
  - type: "mesh"
    file: "meshes/hand.stl"
    center_m: [0.05, 0.05, 0.045]
    rotation_deg: [0.0, 90.0, 0.0]
    scale: 0.001
    smoothing_width_cells: 1.2
    material:
      density: 1250.0
      sound_speed: 2200.0

其中 file 如果使用相对路径，会按当前 YAML 文件所在目录解析。例如配置位于 src/examples/config.yaml，则 file: "meshes/hand.stl" 会解析为 src/examples/meshes/hand.stl。

参数定义

字段 含义
type 障碍物类型。mesh 障碍物必须写为 "mesh"。
file mesh 文件路径。支持 PyVista 可读取的表面网格格式，例如 STL、OBJ、PLY、VTK 等。
center_m 变换后 mesh 轴对齐包围盒中心在求解域中的位置，单位 m。
rotation_deg 绕 X、Y、Z 轴的旋转角，单位 deg。实现中组合矩阵为 \(R_z R_y R_x\)，等价于先绕 X，再绕 Y，再绕 Z 应用到点坐标。
scale mesh 原始单位到米的统一缩放比例。例如原始模型单位是 mm 时，通常设为 0.001。
smoothing_width_cells SDF 到材料参数插值时的平滑半宽，单位为网格单元数。设为 0 表示硬界面。
material.density 障碍物密度，单位 kg/m^3。
material.sound_speed 障碍物声速，单位 m/s。

几何变换规则

mesh_to_sdf() 对 mesh 执行以下变换：

  1. 读取 mesh 并提取三角化表面。
  2. 用原始 mesh 的轴对齐包围盒中心作为局部中心。
  3. 将点坐标平移到局部中心附近。
  4. 乘以统一缩放 scale。
  5. 按 rotation_deg 旋转。
  6. 计算旋转后包围盒中心，并平移到 center_m。

因此 center_m 控制的是最终包围盒中心，不一定是 mesh 原始坐标系的语义中心。

SDF 符号和材料插值

生成的 SDF 与求解器网格同形状：

(nx, ny, nz)

符号约定为：

  • sdf < 0: mesh 内部。
  • sdf = 0: mesh 表面。
  • sdf > 0: mesh 外部。

材料场通过 smooth Heaviside 从障碍物物性过渡到背景空气物性：

epsilon = smoothing_width_cells * dx

当 smoothing_width_cells > 0 时，界面附近会有平滑过渡层；当设为 0 时，使用硬阈值界面。

过渡层中线性混合的是方程里实际出现的两个系数：通量系数 1/rho 与质量项系数 1/(rho c^2)， 再由它们得到 rho 和 c（blend_obstacle_material）：

1/rho        = 1/rho_obs + (1/rho_0 - 1/rho_obs) * H
1/(rho c^2)  = 1/(rho_obs c_obs^2) + (1/(rho_0 c_0^2) - 1/(rho_obs c_obs^2)) * H

这样过渡层的中点落在 SDF 零面上。若直接线性混合 rho，致密障碍物（如 rho=1250，空气的上千倍）在零面外侧 不远处就已在声学上近似刚性，散射等效于一个约大 1 个网格的物体，散射场只按一阶收敛； 对比与修正前后的数据见 docs/BEM_REALTIME_FOCUSING.md。

mesh 质量要求

输入 mesh 必须满足：

  • 表面可被 PyVista 读取。
  • 至少包含可用的闭合表面。
  • 顶点坐标不能包含 NaN 或 infinite。
  • 必须 watertight，没有 open edges。
  • 必须 manifold，没有 non-manifold edges。

如果 mesh 不闭合或非流形，代码会直接报错，避免生成符号不可靠的 SDF。

当前限制

  • 当前求解器一次只支持一个障碍物；多个 obstacles 会触发 NotImplementedError。
  • mesh 可以部分超出求解域，域外部分不会采样；如果整个 mesh 都在域外，会给出 warning。
  • 如果网格没有任何采样点落在 mesh 内部，会给出 warning，说明网格分辨率、缩放或位置可能不合适。
  • 响应基缓存会记录 mesh 文件内容哈希；mesh 文件变化后，旧响应基不能复用。

调试建议

  • 先用较低网格分辨率确认 mesh 的 center_m、rotation_deg 和 scale 是否合理。
  • 运行结果 `.npz` 中会保存 sdf 字段时，可用 python src/algorithm/visualizer.py 查看障碍物表面。
  • 如果看不到障碍物，优先检查单位缩放、mesh 是否在求解域内、以及网格是否太粗。
  • 手部模型侧向伸入时，当前实验约定使用 rotation_deg: [0.0, 90.0, 0.0]。
