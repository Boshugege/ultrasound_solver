# PDE 变参数与多边界修复及验收

日期：2026-10-08。运行环境：conda `srt`，RTX 4070 Laptop 8 GiB。

## 结论与适用范围

解析自由场只承担官方模型对照。实际变密度、变声速、材料界面和混合边界求解仍由
Helmholtz PDE 完成。本次修复了 PDE 的边界离散、材料边界系数和场景缓存；
新增逐网格材料输入、可选 PML、材料伴随梯度，保持相位优化能力。

内部 `div((1/rho) grad p)` 的密度通量形式没有被否定。已经确认的问题主要是：
反射边界的位置偏移，开放边界只处理一个面且使用背景波数，以及修改参数后仍复用旧矩阵。
粗网格本身还存在传播色散，修复边界不能消除它，必须用网格收敛验证相位精度。

本次证明的是受控 PDE 场景中的收敛性、物理边界行为、正向/伴随一致性。
没有声称复杂物体实测、任意入射角或完整 16×16 阵列已经达到硬件相位验收标准。

## 1. 连续模型与离散修复

采用时间约定 `Re(p exp(-i omega t))`，出射波为 `exp(+ikr)`：

```text
div((1/rho(x)) grad p) + omega²/(rho(x)c(x)²) p = f
```

将方程在节点控制体积积分，并除以 `dx³`：

- 内部节点体积权重为 1；外表面、棱、角分别为 1/2、1/4、1/8。
- 每条内部边使用 `2/(rho_i+rho_j)` 密度通量系数，乘对应截面面积权重和 `1/dx²`。
- 两端共用同一边系数，保留复对称矩阵；每个节点累计其所有外边界面的通量。
- 声源和压力释放面的 Dirichlet 行单独处理。消元仅消去这些规定声压行。
- CPU/NumPy 和 GPU/CuPy 共用装配公式，系数 float64、复数 complex128；
  `WarpAssemblyEngine` 保留入口兼容，材料 SDF 插值也采用双精度。

旧方法直接丢弃 reflecting 的缺邻居项，却没有半控制体积权重，相当于移动了壁面。
旧 open 使用单条一阶法向导数方程替换 PDE，并以 `if/elif` 选择第一个面。
现已删除这两种处理，不再保留第二套旧装配公式。

### 六个面的边界配置

| YAML 类型 | 连续条件 | 实现 |
|---|---|---|
| `reflecting` | `∂p/∂n = 0` | 刚壁外向通量为零 |
| `open` | `∂p/∂n = i omega/c(x) p` | 使用局部 `rho,c`，积分通量为 `i omega/(rho c) p` |
| `soft` | `p = 0` | 压力释放 Dirichlet 行 |
| `{type: impedance, impedance: [R,X]}` | `∂p/∂n = i omega rho/Z p` | `Z=R+iX`，单位 Pa·s/m，`R>=0`，积分通量为 `i omega/Z p` |

不同面可以混合；棱角处自然边界通量叠加，Dirichlet 约束优先。
压力释放面与发射器重合时明确报错。未知边界字符串也报错，不再静默当成反射面。

### PML

`solver.pml` 提供坐标拉伸 `s_a=1+i sigma_a`，使用：

```text
∂x[(sy sz)/(rho sx) ∂x p] + ∂y[(sx sz)/(rho sy) ∂y p]
+ ∂z[(sx sy)/(rho sz) ∂z p] + sx sy sz omega²/(rho c²) p = f
```

`sigma = strength * (depth / thickness)^order`，边系数在中点计算。
PML 位于已有计算域内部，不会自动扩展计算域。只允许配置在 open 面；
需要留出不包含声源、目标和散射物的吸收层，并将外部介质平滑延续进入该层。
程序检查声源与 PML 重叠、目标落在 PML 中以及吸收层挤占整个轴向内部的情况。

PML 参数不是全场景免调参数。斜入射验收有明确反射率，仍需针对实际频率、
入射角、层厚和材料延拓做收敛检查。单独的局部 Robin 开放面仍会反射斜入射波。

## 2. 变参数输入、缓存与伴随

材料输入提供三种互斥方式：

1. 原有单个 sphere 或 mesh 的 SDF 平滑材料插值。
2. `physics.material_field_file: materials.npz`，NPZ 包含 `density` 和 `sound_speed`，
   均为 `(nx,ny,nz)` 数组，单位 kg/m³、m/s；相对路径按 YAML 所在目录解析。
3. Python API：`solver.set_material_fields(density, sound_speed)`，内部复制数组。

逐网格数组可以表示任意数量的材料区域和连续梯度；YAML 几何对象列表仍限一个对象。
各区域内的密度和声速都必须有限且大于零。

```python
# 在 src 已加入 Python 路径、cfg.obstacles=[] 且未指定材料 NPZ 时使用
x, y, z = np.indices(tuple(cfg.domain.grid_size)) * cfg.domain.dx
rho = np.where(z < 0.006, 1.21, 1.6)
c = 346.0 + 30.0 * x / cfg.domain.lx
solver.set_material_fields(rho, c)
field = solver.solve()
# dL = Re(field_cotangent^H dp)
grad_rho, grad_c = solver.material_vjp(field, field_cotangent)
```

材料梯度通过一次 `A^H lambda = field_cotangent` 求解计算
`-Re(lambda^H (dA/dtheta) p)`，包括密度边通量、质量项和 open 的局部阻抗项。
源声压幅值、几何、频率、显式阻抗及 PML 拉伸参数在该 API 内保持固定。
调用方须传入当前场景的正向场；此接口不是完整的 SDF 形状优化器或材料反演训练器。

场景指纹覆盖材料、几何、六面边界、PML、声源位置、模型版本和外部文件内容：

- 改变材料或边界后，下一次装配/求解自动失效旧矩阵、GPU 矩阵和分解。
- 网格或阵列规格改变后要求重新创建 solver，避免对象尺寸错配。
- 材料文件或 mesh 文件即使同路径覆盖，也通过内容 SHA256 识别。
- 相位改变仅更新 RHS；固定场景仍可复用响应基。
- 已加载和磁盘上的响应基都拒绝用于改变后的物理场景，须用新路径重建。

逐次改变材料不能继续使用旧的相位响应基。
固定材料下的相位优化与材料参数更新后的 PDE 重求解是两个不同的复用边界。

PDE 目标响应使用复声压三线性插值，并通过同一插值响应求梯度。
这是离散场的插值，不是官方解析模型。另修复了 GPU 格点焦点损失中
`cupy.add.at` 不支持 complex128 的运行时问题，改为实部、虚部分别累加。

| 指标 | 修复前 | 修复后 |

| 65 点，法向出射复场相对 L2 误差 | 1.8108% | 0.037991% |

### 斜入射与材料伴随

- 约 42° 波导模式：局部 Robin 反射幅度 **14.6934%**，
  24 层、三次 PML 降至 **0.45243%**，约降低 32.5 倍。
- 变密度/声速、反射/开放/阻抗/压力释放混合边界，cuDSS 正向相对残差
  **1.96×10⁻⁹**，伴随相对残差 **7.17×10⁻¹⁶**，凝聚矩阵复对称误差 **0**。
- 材料联合方向导数：伴随结果 `-1.61437491013e-4`。
  中心差分步长 `1e-3/1e-4/1e-5` 时，相对误差分别
  **2.73×10⁻⁸ / 3.83×10⁻¹⁰ / 1.67×10⁻⁹**。
- 另覆盖含 PML 的材料梯度、CPU/CUDA 矩阵一致性、
  相位响应基与直接 PDE 场一致性、相位梯度、重复目标 GPU 累加和文件覆盖缓存失效。

小线性残差只说明离散系统被正确求解。物理精度由上述独立参考和网格收敛共同验证。

## 4. 运行方法

从项目根目录：

```powershell
conda activate srt
$env:CUPY_CACHE_IN_MEMORY = "1"
$env:WARP_CACHE_PATH = "$PWD\.dbg\warp_cache"
python src/main.py --config src/examples/pde_variable_mixed.yaml
```

示例为 16 mm 立方体、33³ 网格、2×2 发射器；球形区域同时改变密度和声速，
四种边界并存，+y/+z 使用 PML，从随机相位优化非网格目标
`(9.3,7.1,10.2) mm`。输出目录 `outputs/pde_variable_mixed/`。
小阵列用于端到端验收，不能拿此配置直接驱动 16×16 硬件。

修复阶段回归已通过；示例经过 **18 次场/梯度评估**收敛。
目标仿真声压由 **3758.441 Pa** 增至 **6619.090 Pa**（约 +76.1%）。
使用独立 SciPy 插值重新计算该离散 PDE 响应的固定幅值单点上限，
同样为 **6619.090 Pa**，优化结果达到该离散模型上限。
保存复场与响应基重建场的相对 L2 差为 **1.17×10⁻¹⁶**。
这些幅值属于示例的声压圆盘标定，不代表硬件实测。
数值归档：`docs/pde_example_verification.json`；
日志：`.dbg/pde-final-tests.log`、`.dbg/pde-mixed-example.log`。

如需改为多个任意材料区域，删除示例 `obstacles`，设置材料 NPZ；
不能同时叠加两种材料输入。改变材料后请改用新的 `phase_basis_file` 路径。

## 5. 当前限制及下一阶段验收

- PDE 仍为标量无损声学，支持正实数密度/声速。没有声称实现黏热损耗、
  弹性固体横波、流固耦合或任意曲面上的独立边界条件；六面边界属于外部笛卡尔盒。
- 当前发射器是规定声压圆盘，官方是归一化 sinc 点源，两者的近场、
  指向性和边缘作用并不相同。最终硬件相位比较还需统一源模型或做源面标定。
- 现在拒绝少于最短局部波长 6 点的网格；10～20 点只是起点，
  长距离累计相位误差必须继续加密验证。不能把代数收敛当作相位收敛。
- 8 GiB GPU 上完整 16×16 阵列、足够细网格的三维分解和全体积响应基
  尚未做资源验收。响应基 complex128 内存为 `N_voxel × 256 × 16` 字节，
  扩展计算域和增加 PML 都会放大成本，需要单独规划求解器与存储。
- 全反射且无阻尼的封闭域在共振频率附近可能病态，这是物理模型性质。
