Gradient Derivation for Phase-Only and PDE Adjoint Optimization

纯相位优化与 PDE 伴随梯度推导

本文档补齐求梯度主线：当前已实现的是固定场景下的相位梯度，使用响应基 \(G=A^{-1}B\) 做解析 VJP；如果未来优化障碍物几何、SDF 或材料参数，则需要使用 PDE 伴随法。

符号约定

\(u\in\mathbb{C}^{N}\) 完整三维复声压场。
\(\phi\in\mathbb{R}^{M}\) 换能器相位，当前 phase-only 优化的变量。

\(B\in\mathbb{C}^{N\times M}\) 换能器源矩阵，第 \(r\) 列表示第 \(r\) 个阵元的零相位激励。
\(G=A^{-1}B\) 固定场景相位响应基。
\(a=|u|\) 振幅场。
\(c\in\mathbb{C}^{N}\) 损失对复声场的 cotangent；等价于把 \(\partial L/\partial\operatorname{Re}(u)\) 和 \(\partial L/\partial\operatorname{Im}(u)\) 合并成一个复向量。
\(L\) 实值优化目标。

先把 \(B\) 说清楚：它是“阵元激励到网格右端”的映射

一句话：\(B\) 的第 \(r\) 列表示“只让第 \(r\) 个阵元以配置幅值、零相位工作时，完整 Helmholtz 方程右端 \(b\) 应该填成什么样”。它描述输入放在哪里，不是传播后的声场。

\(A\)：传播规律

网格、介质、障碍物和边界如何耦合所有复声压未知量。

shape = (N, N)

\(B\)：声源输入

每个阵元的归一化 sinc Neumann 孔径通量经有限体积积分后形成的 RHS。

shape = (N, M)

\(G=A^{-1}B\)：全场响应

每个阵元单独工作时，在所有网格点产生的完整复声压。

shape = (N, M)

其中：

  • \(N=N_xN_yN_z\)：完整三维网格自由度数。
  • \(M\)：阵元数；当前 16×16 阵列有 \(M=256\)。
  • \(A_r\)：第 \(r\) 个阵元的归一化驱动幅值。
  • \(\phi_r\)：第 \(r\) 个阵元当前相位。

这里说的是完整离散系统中的概念形状。边界凝聚会在求解器内部把 \(B\) 的每一列转换成约化右端，求解后再恢复全部 \(N\) 个网格点，所以最终保存的 \(G\) 仍是 \(N\times M\)。

\(B\) 的一列具体是什么？

设 \(S_{j,r}\) 为第 \(r\) 个孔径经求积、双线性沉积及 \(-2\pi/(\rho_{\mathrm{ref}}h^3)\) 缩放后在自由度 \(j\) 上的源系数。 第 \(r\) 列 \(b_r=B_{:,r}\) 为：

\[ (b_r)_j = A_r S_{j,r} \]

因此一列只在该阵元孔径沉积到的底面节点上非零。此时相位为零：

\[ A_r e^{i\cdot 0}=A_r \]

其他阵元在这一列的右端激励为零，但底面仍作为统一的 reflecting 控制体积矩阵存在；没有任何阵元节点被替换为规定声压行。

一个可以直接看懂的小矩阵

假设只有 8 个网格自由度和 3 个阵元：

                      阵元 1      阵元 2      阵元 3
                  ┌                                   ┐
底面节点 1        │  A₁S₁₁         0           0      │
底面节点 2        │  A₁S₂₁      A₂S₂₂          0      │
底面节点 3        │     0       A₂S₃₂       A₃S₃₃    │
底面节点 4        │     0          0        A₃S₄₃    │
体内节点 5..8     │     0          0           0      │
                  └                                   ┘

S 的每列来自单位质量孔径的双线性沉积；
相邻孔径的沉积支撑可在同一网格节点相加。

给三个阵元施加相位后，令：

w = [exp(iφ₁), exp(iφ₂), exp(iφ₃)]ᵀ

普通矩阵乘法 \(b(\phi)=Bw\) 得到：

b(φ) =
B [exp(iφ₁), exp(iφ₂), exp(iφ₃)]ᵀ

这正是完整 Helmholtz 右端：各阵元孔径通量按复权重线性叠加， 非声源体内节点右端为零。

更精确的结构写法：\(B=S\,\mathrm{diag}(A)\)

定义归一化孔径到网格 RHS 的稀疏沉积矩阵 \(S\)， 再定义阵元幅值向量 \(A=[A_1,\ldots,A_M]^T\)，则：

\[ B=S\,\mathrm{diag}(A_1,\ldots,A_M), \qquad b(\phi)=B e^{i\phi} \]

当前代码使用单位归一化阵元幅值：

A₁ = A₂ = ... = A₂₅₆ = 1

所以当前单位幅值条件下：

\[ B=S,\qquad b(\phi)=B e^{i\phi} \]

这通常不是张量积。孔径求积点经过双线性沉积， 每列包含不同的连续权重；实现不依赖阵元中心与网格对齐。

为什么 \(B\) 非常稀疏？

  • 只有底面孔径求积点沉积到的网格节点可能非零。
  • 每个求积点按双线性权重写入相邻四个节点。
  • 每个阵元列的沉积质量严格归一化为 1。
  • 求积支撑、PML、侧边界或 soft 面冲突会在装配时明确报错。

不要把“\(B\) 很稀疏”和“\(G\) 很稀疏”混淆。一个局部声源通过 Helmholtz 方程传播到全空间，因此：

B 的一列：只在少量声源网格点非零       → 稀疏输入
G 的一列：一个阵元产生的完整三维声场   → 通常稠密输出

代码中的稀疏 \(B\)

source_mass_matrix() 直接生成稀疏孔径质量矩阵， flux_rhs_columns() 将其扩展为完整三维系统的 Neumann RHS 列。 构建全场响应基时仍可按 phase_basis_batch_size 分批求解：

rhs = zeros((N, batch_size))

rhs = source_columns[:, this_batch]

G[:, this_batch] = solve(A, rhs)

当前 55³、16×16 示例的批大小为 16：

概念上的完整 B：166375 × 256
一次实际构造的 RHS：166375 × 16

complex128 下：
完整稠密 B 约 650 MiB

这里的内存数字按分批直接求解接口的稠密 RHS 计算；源列本身以稀疏矩阵保存， 从而避免长期保存完整稠密 \(B\)，同时复用同一份矩阵分解。

从 \(B\) 到 \(G\)：列的物理意义没有改变

第 \(r\) 个输入列 \(b_r\) → 求解 \(A g_r=b_r\) → 第 \(r\) 个全场响应 \(g_r\)
\[ G=[g_1,\ldots,g_M] = [A^{-1}b_1,\ldots,A^{-1}b_M] \]

关键点：代码从不显式计算 \(A^{-1}\)

\(A^{-1}B\) 是线性算子的数学记号，不表示先生成一个稠密逆矩阵 \(A^{-1}\)。实际计算始终是求解线性方程 \(Ag_r=b_r\)。显式求逆不仅需要巨大内存，通常也比基于分解的线性求解更慢、数值稳定性更差。

把 \(B\) 和 \(G\) 按列展开：

\[ B=[b_1,b_2,\ldots,b_M], \qquad G=[g_1,g_2,\ldots,g_M] \]

矩阵方程 \(AG=B\) 等价于 \(M\) 个相互独立、但系数矩阵完全相同的向量方程：

\[ \begin{aligned} Ag_1 &= b_1,\\ Ag_2 &= b_2,\\ &\ \vdots\\ Ag_M &= b_M. \end{aligned} \]

因此，即使某个底层求解器只接受一个向量右端，也仍然能够逐列得到 \(G\)。真正重要的是所有列都使用同一个 \(A\)，所以昂贵的矩阵分析和数值分解只需要执行一次。

factor = factorize(A)           # 只执行一次

for each batch of B:
    for each column b_r in batch:
        g_r = solve_with_factor(factor, b_r)
        G[:, r] = g_r

可以把这个过程理解为：

一次装配 \(A\) → 一次分析与分解 → 复用因子求解 256 个右端 → 保存 256 列 \(G\)

若直接求解器把 \(A\) 分解为适合其矩阵类型的三角因子，那么每个新的 \(b_r\) 只需要进行前代和回代，不需要重新分解 \(A\)。这就是响应基预计算能够承受 256 个阵元右端的原因。

“矩阵右端”只是多个向量右端的统一接口

当前 solve_rhs() 同时接受两种形状：

rhs.shape = (N,)        # 一个向量右端
rhs.shape = (N, nrhs)   # nrhs 个向量右端

例如当前批大小为 16 时，调用：

\[ A \begin{bmatrix} g_r & g_{r+1} & \cdots & g_{r+15} \end{bmatrix} = \begin{bmatrix} b_r & b_{r+1} & \cdots & b_{r+15} \end{bmatrix} \]

这在数学上仍是 16 个独立的线性方程。当前边界处理可以对这 16 列一起做矩阵运算；当前 cuDSS 封装则在内部逐列设置 RHS 并调用求解，但每一列都复用同一份 cuDSS 分解因子。

# 当前 cuDSS 包装层的等价逻辑
for column in range(rhs_matrix.shape[1]):
    rhs_buffer[:] = rhs_matrix[:, column]
    result[:, column] = factorized_solver.solve(rhs_buffer)

所以“批大小为 16”不代表只进行了 16 次向量求解。当前共有 256 个阵元，数学上仍需要 256 个右端求解；它们被组织成 16 批，每批 16 列。分批主要用于控制 RHS 临时内存、减少接口管理开销，并支持中断后按已完成列继续构建。

边界凝聚后，一批 \(B\) 如何恢复成完整 \(G\)

实际求解不会直接分解完整的原始矩阵。把自由度分成保留部分 \(R\) 和被消去的边界部分 \(E\)，对一批右端可写成：

\[ \begin{bmatrix} A_{RR} & A_{RE}\\ A_{ER} & A_{EE} \end{bmatrix} \begin{bmatrix} G_R\\ G_E \end{bmatrix} = \begin{bmatrix} B_R\\ B_E \end{bmatrix}. \]

首先处理被消去边界上的这一批右端：

\[ Y=A_{EE}^{-1}B_E. \]

然后构造约化矩阵和约化右端：

\[ S=A_{RR}-A_{RE}A_{EE}^{-1}A_{ER}, \qquad \widetilde B_R=B_R-A_{RE}Y. \]

使用同一份约化矩阵分解求解所有保留自由度：

\[ S G_R=\widetilde B_R. \]

最后通过边界传递矩阵 \(T=-A_{EE}^{-1}A_{ER}\) 恢复完整边界响应：

\[ G_E=Y+T G_R. \]

因此，cuDSS 实际分解和求解的是更小的约化系统 \(S\)，但响应基文件中保存的每一列仍然是恢复后的完整三维声场：

\[ G= \begin{bmatrix} G_R\\ G_E \end{bmatrix} \in\mathbb{C}^{N\times M}. \]

因此 \(G\) 第 \(r\) 列已经包含第 \(r\) 个阵元的固定幅值 \(P_r\)。在线乘的 \(w_r=e^{i\phi_r}\) 只有相位、模长为 1，不会再次乘一次 \(P_r\)。

最直观的记忆方式：\(C\) 回答“第几个阵元对应哪些网格点”，\(\mathrm{diag}(P)\) 回答“每个阵元有多大幅值”，\(w=\exp(i\phi)\) 回答“每个阵元当前转了多少相位”，而 \(A^{-1}\) 回答“这些局部输入如何传播成完整声场”。

当前 phase-only 前向模型

固定障碍物、介质、边界条件、阵元位置和阵元幅值后，系统矩阵不随相位变化：

\[ A u(\phi)=b(\phi) \]

相位只进入右端项；幅值已包含在 \(B\) 中：

\[ b(\phi)=B\exp(i\phi) \]

预计算响应基：

\[ G=A^{-1}B \]

在线优化时的完整声场为：

\[ u(\phi)=G\exp(i\phi) \]

这一步没有自由空间近似；\(G\) 的每一列都是在当前障碍物和边界条件下，由一个阵元以配置幅值、零相位激励完整 PDE 得到的全场响应。

复数场到振幅 loss 的导数

先给结论：field_cotangent 不是近似梯度，也不是人为绕过求导的中间量。它是损失函数对声场实部和虚部的普通实梯度，用一个复向量表示后的结果。最终交给 Adam、L-BFGS-B 等优化器的仍是严格意义下的实数相位梯度 \(\nabla_\phi L\in\mathbb{R}^{M}\)。

为什么不能直接写普通的 \(\partial L/\partial u\)？

复声压可写成：

\[ u=x+i y, \qquad x,y\in\mathbb{R}^{N}. \]

当前 loss 依赖振幅：

\[ |u|=\sqrt{u\,u^*}=\sqrt{x^2+y^2}. \]

因为 \(|u|\) 同时依赖 \(u\) 和共轭 \(u^*\)，它不满足复变函数的柯西－黎曼条件，不能把 \(L(|u|)\) 当成关于 \(u\) 的解析函数使用普通复导数。严谨做法是把它视为定义在 \(\mathbb{R}^{2N}\) 上的实值函数：

\[ L=L(x,y), \qquad L:\mathbb{R}^{2N}\rightarrow\mathbb{R}. \]

它的普通实数全微分为：

\[ dL= \left(\frac{\partial L}{\partial x}\right)^Tdx + \left(\frac{\partial L}{\partial y}\right)^Tdy. \]

这就是后续所有复数写法的起点；没有改变变量，也没有省略实数链式法则。

\(c\) 是两个实梯度的复数封装

定义复向量：

\[ c= \frac{\partial L}{\partial x} i\frac{\partial L}{\partial y}. \]

因此：

\[ \operatorname{Re}(c) = \frac{\partial L}{\partial x}, \qquad \operatorname{Im}(c) = \frac{\partial L}{\partial y}. \]

又因为 \(du=dx+i\,dy\)，所以：

\[ \begin{aligned} \operatorname{Re}(c^Hdu) &= \operatorname{Re} \left[ \left( \frac{\partial L}{\partial x} i\frac{\partial L}{\partial y} \right)^H (dx+i\,dy) \right]\\ &= \left(\frac{\partial L}{\partial x}\right)^Tdx + \left(\frac{\partial L}{\partial y}\right)^Tdy\\ &=dL. \end{aligned} \]

于是可以把普通实数全微分紧凑地写为：

\[ \boxed{ dL=\operatorname{Re}(c^Hdu) }. \]

其中 \(H\) 表示共轭转置。必须取实部，因为 \(L\) 和 \(dL\) 都是实数，而 \(c^Hdu\) 本身可能含有虚部。

\(du\)：场的变化

描述所有网格点的复声压沿什么方向发生微小变化。

shape = (N,)

\(c\)：输出端敏感度

给定任意 \(du\)，通过实内积计算对应的一阶损失变化。

shape = (N,)

\(dL\)：标量变化

满足 \(L(u+du)=L(u)+dL+o(\lVert du\rVert)\)。

shape = scalar

为什么它叫 cotangent，而不直接叫 gradient？

在反向模式自动微分中，上游传回来的对象描述一个线性映射：

\[ du \longmapsto dL=\operatorname{Re}(c^Hdu). \]

\(du\) 是输出空间中的变化方向（tangent），而 \(c\) 表示作用在这个方向上的线性泛函，因此称为 cotangent。选定实内积 \(\langle a,b\rangle_{\mathbb R}=\operatorname{Re}(a^Hb)\) 后，cotangent 可以由向量 \(c\) 唯一表示，所以它也可以直观地称为“复声场梯度”。代码使用 field_cotangent 是为了强调它是传给 VJP 的输出端敏感度。

它与 Wirtinger 导数的关系是：

\[ \frac{\partial L}{\partial u^*} = \frac12 \left( \frac{\partial L}{\partial x} + i\frac{\partial L}{\partial y} \right), \qquad \boxed{ c=2\frac{\partial L}{\partial u^*} }. \]

不同论文和自动微分框架可能把 \(\partial L/\partial u^*\) 或 \(2\partial L/\partial u^*\) 称为“复梯度”，因而看起来相差因子 2。本文通过明确规定 \(dL=\operatorname{Re}(c^Hdu)\) 固定了约定，后续公式和代码都使用同一约定。

它与普通实数链式法则完全等价

相位 \(\phi\in\mathbb{R}^{M}\) 才是优化变量。设：

\[ u(\phi)=x(\phi)+i\,y(\phi). \]

直接在实数域应用链式法则，应得到：

\[ \nabla_\phi L = \left(\frac{\partial x}{\partial\phi}\right)^T \frac{\partial L}{\partial x} + \left(\frac{\partial y}{\partial\phi}\right)^T \frac{\partial L}{\partial y}. \]

把 \(c=\partial L/\partial x+i\,\partial L/\partial y\) 和 \(du=(\partial u/\partial\phi)d\phi\) 代入 \(\operatorname{Re}(c^Hdu)\)，展开后恰好得到上式。因此复数 VJP 只是对同一个实数 Jacobian 转置乘法的紧凑实现：

\[ \underbrace{ \begin{bmatrix} \partial x/\partial\phi\\ \partial y/\partial\phi \end{bmatrix}^{T} \begin{bmatrix} \partial L/\partial x\\ \partial L/\partial y \end{bmatrix} }_{\text{普通实数 VJP}} = \underbrace{ \nabla_\phi L }_{\text{最终实数相位梯度}}. \]

代码中的职责边界为：

loss 根据 \(u\) 解析计算 \(c\) → phase_vjp(c, phases) → 输出 \(\nabla_\phi L\in\mathbb{R}^{M}\)

优化器不会直接使用 \(c\)。它只接收最终的普通实数数组 gradient[r] = ∂L/∂φ_r。

零振幅处的严格性边界

振幅函数 \(|u|\) 在 \(u=0\) 处不可微，因为此处没有唯一方向。当前实现使用：

\[ \frac{u}{|u|+\epsilon} \]

避免除零，并在 \(u=0\) 时返回零方向。对于 \(|u|\gg\epsilon\) 的点，它与解析导数 \(u/|u|\) 几乎一致；但严格地说，这是零点附近的数值正则化。

如果需要构造处处光滑且 loss 与导数完全一致的形式，可以同时把振幅定义改为：

\[ a_\epsilon(u)=\sqrt{|u|^2+\epsilon^2}, \qquad da_\epsilon = \operatorname{Re} \left[ \left( \frac{u}{\sqrt{|u|^2+\epsilon^2}} \right)^* du \right]. \]

当前代码取 \(\epsilon=10^{-12}\)，主要用于数值保护。解析相位梯度还会与中心有限差分结果逐项比较，从实现层面检查符号、共轭、因子 2 和相位链式法则。

field_match

目标是匹配完整目标振幅场：

\[ L=\frac12\sum_j \left[ W_j\left(|u_j|-a^{target}_j\right) \right]^2 \]

令 \(r_j=|u_j|-a^{target}_j\)，则：

对于 \(u_j=x_j+i\,y_j\neq 0\)，振幅的微分为：

\[ \begin{aligned} d|u_j| &= \frac{x_j\,dx_j+y_j\,dy_j}{|u_j|}\\ &= \operatorname{Re} \left( \frac{u_j^*}{|u_j|}du_j \right). \end{aligned} \]

第 \(j\) 个网格点的损失微分为：

\[ \begin{aligned} dL_j &= W_j^2r_j\,d|u_j|\\ &= \operatorname{Re} \left[ \left( W_j^2r_j\frac{u_j}{|u_j|} \right)^* du_j \right]. \end{aligned} \]

与定义 \(dL_j=\operatorname{Re}(c_j^*du_j)\) 逐项比较，得到：

\[ c_j= W_j^2 r_j \frac{u_j}{|u_j|+\epsilon} \]

其中分母中的 \(\epsilon\) 是代码加入的零振幅保护；忽略该数值正则项时，上式就是前面严格推导出的 \(u_j/|u_j|\)。

单个复声压的数值核对

设某网格点 \(u=3+4i\)，目标振幅为 6，权重为 1，则：

\[ |u|=5, \qquad r=5-6=-1, \qquad c=r\frac{u}{|u|}=-0.6-0.8i. \]

若声场发生微小变化 \(du=0.01+0.02i\)，cotangent 公式给出：

\[ dL = \operatorname{Re}(c^*du) = \operatorname{Re} \left[ (-0.6+0.8i)(0.01+0.02i) \right] = -0.022. \]

直接在实数域计算也得到：

\[ d|u| = \frac{3(0.01)+4(0.02)}{5} = 0.022, \qquad dL=r\,d|u|=-0.022. \]

两种结果完全一致，说明 cotangent 表示没有改变导数，只是把实部梯度和虚部梯度合并在一个复数中。

对应代码：

cotangent = weight * weight * residual * field / (amplitude + eps)

focal_pressure

目标是直接提高目标点振幅，同时可选压低全局平均能量：

\[ L= -\frac{\alpha}{K} \sum_{k=1}^{K}|u_{t_k}| + \frac{\beta}{2N} \sum_j |u_j|^2 \]

目标点处的 cotangent 为：

\[ c_{t_k}= -\frac{\alpha}{K} \frac{u_{t_k}}{|u_{t_k}|+\epsilon} \]

背景能量项贡献为：

\[ c_j \mathrel{+}= \frac{\beta}{N}u_j \]

focal_contrast

当前主推 loss 是目标点振幅与旁瓣参考值的对比：

\[ L=-\alpha\ \mathrm{mean}_{k}(|u_{t_k}|) +\beta\ \mathrm{smoothmax}_{j\in\Omega_{bg}}(|u_j|) \]

其中背景区域 \(\Omega_{bg}\) 会排除：

  • 目标点附近半径 training.target_radius 内的区域。
  • 底部源面附近 training.source_exclusion_layers 层网格。

平滑最大值使用稳定形式：

\[ m=\max_{j\in\Omega_{bg}} |u_j| \] \[ p_j= \frac{ \exp((|u_j|-m)/T) }{ \sum_{\ell\in\Omega_{bg}} \exp((|u_\ell|-m)/T) } \] \[ \mathrm{smoothmax} = m+ T\left[ \log\sum_{j\in\Omega_{bg}} \exp((|u_j|-m)/T) - \log|\Omega_{bg}| \right] \]

背景项 cotangent 为：

\[ c_j \mathrel{+}= \beta p_j \frac{u_j}{|u_j|+\epsilon}, \qquad j\in\Omega_{bg} \]

响应基下的相位梯度

这一节的目标：已知 loss 对完整复声场的 cotangent \(c\)，求每个实数阵元相位的梯度 \(\partial L/\partial\phi_r\)。这是从 \(N\) 个网格点的场敏感度反向汇总到 \(M\) 个阵元的过程。

公式中的符号分别表示什么？

符号 形状 含义
\(\phi_r\) 实数标量 第 \(r\) 个阵元的待优化相位。
\(G_{:,r}\) \(\mathbb{C}^{N}\) 响应基 \(G\) 的第 \(r\) 列，即第 \(r\) 个阵元以配置幅值、零相位激励时的完整复声场。
\(c\) \(\mathbb{C}^{N}\) loss 对完整复声场的 cotangent，满足 \(dL=\operatorname{Re}(c^Hdu)\)。
\((\cdot)^H\) — 共轭转置；\(G^H=\overline G^T\)。
\(\overline z\) \(\mathbb{C}^{M}\) 向量 \(z\) 的逐元素复共轭。
\(\odot\) — Hadamard 乘积，即相同位置逐元素相乘，不是矩阵乘法。
\(\nabla_\phi L\) \(\mathbb{R}^{M}\) 最终交给优化器的相位梯度，每个阵元对应一个实数。

第一步：把声场写成所有阵元响应的叠加

令阵元复权重为：

\[ w=\exp(i\phi), \qquad w_r=e^{i\phi_r}. \]

响应基前向模型为：

\[ u=Gw = \sum_{r=1}^{M} G_{:,r}e^{i\phi_r}. \]

这里 \(G_{:,r}\) 已经包含第 \(r\) 个阵元的固定幅值和完整 PDE 传播结果；\(e^{i\phi_r}\) 只负责旋转该列响应的复相位。

第二步：求声场对单个相位的导数

当只改变 \(\phi_r\) 时，求和式中只有第 \(r\) 项变化。由复指数的普通实变量导数：

\[ \frac{d}{d\phi_r}e^{i\phi_r} = i e^{i\phi_r}, \]

得到：

\[ \boxed{ \frac{\partial u}{\partial\phi_r} = iG_{:,r}e^{i\phi_r} }. \]

这个导数是长度为 \(N\) 的复向量，描述第 \(r\) 个阵元相位发生单位微小变化时，所有网格点的复声压分别如何变化。

第三步：使用全微分读出单个相位梯度

只对第 \(r\) 个相位施加微小扰动 \(d\phi_r\) 时：

\[ du= \frac{\partial u}{\partial\phi_r}d\phi_r. \]

代入复声场全微分定义：

\[ \begin{aligned} dL &= \operatorname{Re}(c^Hdu)\\ &= \operatorname{Re} \left[ c^H \frac{\partial u}{\partial\phi_r} \right]d\phi_r. \end{aligned} \]

另一方面，普通实变量微分满足 \(dL=(\partial L/\partial\phi_r)d\phi_r\)。比较 \(d\phi_r\) 前的系数：

\[ \boxed{ \frac{\partial L}{\partial\phi_r} = \operatorname{Re} \left[ c^H \left( iG_{:,r}e^{i\phi_r} \right) \right] }. \]

它的物理意义是：先计算“第 \(r\) 个阵元的相位变化会造成怎样的全场变化”，再与 loss 对全场的敏感度 \(c\) 做实内积，得到该相位对 loss 的一阶影响。

第四步：用一次 \(G^Hc\) 同时处理所有阵元

若逐个计算上一公式，需要对每个阵元分别执行一次长度为 \(N\) 的内积。定义：

\[ z=G^Hc \]

维度为：

\[ G^H\in\mathbb{C}^{M\times N}, \qquad c\in\mathbb{C}^{N}, \qquad z\in\mathbb{C}^{M}. \]

\(z\) 的第 \(r\) 个元素为：

\[ z_r=G_{:,r}^Hc. \]

因此 \(z_r\) 是第 \(r\) 个阵元的完整场响应 \(G_{:,r}\) 与全场 loss 敏感度 \(c\) 的复内积，可以理解为“从整个空间反向汇总到第 \(r\) 个阵元的复敏感度”。

为什么最终公式中出现 \(\overline z\)？

单阵元公式中出现的是 \(c^HG_{:,r}\)，而 \(z_r\) 的定义是 \(G_{:,r}^Hc\)。二者互为复共轭：

\[ c^HG_{:,r} = \left(G_{:,r}^Hc\right)^* = \overline{z_r}. \]

所以单阵元梯度可以改写为：

\[ \frac{\partial L}{\partial\phi_r} = \operatorname{Re} \left[ \overline{z_r}\, i e^{i\phi_r} \right]. \]

把全部 \(M\) 个阵元合并成一个向量，就得到代码中使用的公式：

\[ \boxed{ \nabla_\phi L = \operatorname{Re} \left[ \overline{z} \odot i\exp(i\phi) \right] }. \]

这里使用 \(\odot\) 是因为每个 \(z_r\) 只与同一个阵元的 \(i e^{i\phi_r}\) 相乘：

\[ \overline z\odot i\exp(i\phi) = \begin{bmatrix} \overline{z_1}i e^{i\phi_1}\\ \overline{z_2}i e^{i\phi_2}\\ \vdots\\ \overline{z_M}i e^{i\phi_M} \end{bmatrix}. \]

等价的更紧凑形式

利用复数恒等式 \(\operatorname{Re}(iq)=-\operatorname{Im}(q)\)，还可以得到：

\[ \boxed{ \nabla_\phi L = \operatorname{Im} \left[ \exp(-i\phi)\odot G^Hc \right] }. \]

两种表达完全等价。当前实现选择第一种形式，因为它直接对应“先算 \(G^Hc\)，再乘 \(d e^{i\phi}/d\phi=i e^{i\phi}\)”这一链式法则。

代码与公式逐项对应

对应实现：

weights = exp(1j * phases)

这一步称为 VJP（Vector–Jacobian Product，向量–雅可比积），因为它直接计算 loss 敏感度与声场 Jacobian 的乘积，而不显式创建尺寸约为 \(N\times M\) 的 Jacobian。一次 \(G^Hc\) 就能汇总所有网格点并得到全部阵元的反向敏感度。

相位 \(\phi\) → 权重 \(w=e^{i\phi}\) → 声场 \(u=Gw\) → loss 得到 \(c\) → \(z=G^Hc\) → 实数梯度 \(\nabla_\phi L\)

与 PDE 伴随法的关系

伴随方程右端 \(c\) 从哪里来？

一句话：\(c\) 只由 loss 对当前声场 \(u\) 的导数决定，与如何求解 PDE 无关。它不是材料系数，也不是真实换能器激励；在伴随方程中，它扮演“损失敏感度源”的角色。

对第 \(j\) 个网格点，写成：

\[ u_j=x_j+i\,y_j. \]

首先完全按照普通实变量求导，得到：

\[ \frac{\partial L}{\partial x_j}, \qquad \frac{\partial L}{\partial y_j}. \]

再把这两个实数合并为一个复数：

\[ \boxed{ c_j= \frac{\partial L}{\partial x_j} i\frac{\partial L}{\partial y_j} }. \]

因此完整的 \(c\) 是由所有网格点敏感度组成的向量：

\[ c= \begin{bmatrix} c_1&c_2&\cdots&c_N \end{bmatrix}^{T} \in\mathbb{C}^{N}. \]

这个定义保证任意微小声场变化 \(du\) 引起的损失变化都满足：

\[ dL= \operatorname{Re}(c^Hdu). \]

所以 \(c_j\) 的含义不是“网格点 \(j\) 的声压”，而是：

如果网格点 \(j\) 的复声压沿某个方向发生微小变化，这个变化会让 loss 增加还是减小，以及变化有多快。

对于振幅 loss，\(c_j\) 如何直接算出？

若某点的损失写成 \(L_j=f(|u_j|)\)，令 \(a_j=|u_j|\)，则普通链式法则给出：

\[ dL_j=f'(a_j)\,da_j. \]

又因为：

\[ da_j = \operatorname{Re} \left( \frac{u_j^*}{|u_j|}du_j \right), \]

所以：

\[ dL_j = \operatorname{Re} \left[ \left( f'(|u_j|) \frac{u_j}{|u_j|} \right)^* du_j \right]. \]

与 \(dL_j=\operatorname{Re}(c_j^*du_j)\) 对比：

\[ \boxed{ c_j= f'(|u_j|) \frac{u_j}{|u_j|} }. \]

这里两部分的作用不同：

  • \(f'(|u_j|)\)：决定 loss 希望该点振幅增大还是减小，以及敏感度大小。
  • \(u_j/|u_j|\)：给出当前复声压在复平面中的方向。

例如目标点增益项：

\[ L_{\mathrm{target}} = -\frac{\alpha}{K} \sum_{k=1}^{K}|u_{t_k}| \]

对应目标点上的 \(c\) 为：

\[ c_{t_k} = -\frac{\alpha}{K} \frac{u_{t_k}}{|u_{t_k}|+\epsilon}. \]

非目标点如果没有出现在 loss 中，则其直接敏感度为零；如果 loss 还包含旁瓣惩罚，那么背景区域也会产生非零的 \(c_j\)。

为什么 \(c\) 会成为伴随方程的右端？

正向 PDE 为：

\[ A(\theta)u=b(\theta). \]

对参数 \(\theta\) 求导：

\[ A\frac{\partial u}{\partial\theta} = \frac{\partial b}{\partial\theta} - \frac{\partial A}{\partial\theta}u. \]

而 loss 对参数的导数为：

\[ \frac{dL}{d\theta} = \operatorname{Re} \left[ c^H\frac{\partial u}{\partial\theta} \right]. \]

如果直接代入 \(\partial u/\partial\theta\)，每个参数都可能需要一次新的大型 PDE 求解。为消去这个量，定义伴随变量 \(\lambda\) 满足：

\[ \boxed{ A^H\lambda=c }. \]

对上式取共轭转置可得：

\[ c^H=\lambda^H A. \]

代回损失导数：

\[ \begin{aligned} \frac{dL}{d\theta} &= \operatorname{Re} \left[ \lambda^H A \frac{\partial u}{\partial\theta} \right]\\ &= \operatorname{Re} \left[ \lambda^H \left( \frac{\partial b}{\partial\theta} - \frac{\partial A}{\partial\theta}u \right) \right]. \end{aligned} \]

这就是 \(A^H\lambda=c\) 的来源：不是凭空规定一个方程，而是为了用 \(c^H=\lambda^HA\) 消去昂贵的 \(\partial u/\partial\theta\)。

“损失敏感度源”的物理直觉

正向右端 \(b\)

描述真实换能器从哪些边界网格点向系统输入声压。

伴随右端 \(c\)

描述 loss 在哪些网格点关心声场，以及希望这些位置怎样变化。

伴随场 \(\lambda\)

把目标区和背景区的敏感度通过 \(A^H\) 反向传播到整个计算域。

如果 loss 只关心一个目标点，那么 \(c\) 主要只在该目标点非零。求解 \(A^H\lambda=c\) 可以直观理解为从目标点放置一个虚拟伴随源，再把它对整个场景的影响反向传播出去。

它与响应基 VJP 是同一件事

固定场景下 \(G=A^{-1}B\)，因此：

\[ G^Hc = (A^{-1}B)^Hc = B^HA^{-H}c. \]

若定义 \(\lambda=A^{-H}c\)，也就是求解 \(A^H\lambda=c\)，则：

\[ \boxed{ G^Hc=B^H\lambda }. \]

因此响应基路径中的 \(G^Hc\) 与 PDE 伴随路径中的“先求 \(\lambda\)，再计算 \(B^H\lambda\)”在数学上完全等价。区别只是固定场景时已经预计算了 \(G\)，所以在线优化不必每轮重新求解伴随 PDE。

最终的通用参数梯度

对于会改变系统矩阵或右端的任意参数 \(\theta\)，上面的推导最终给出：

\[ \boxed{ \frac{dL}{d\theta} = \operatorname{Re} \left[ \lambda^H \frac{\partial b}{\partial\theta} - \lambda^H \frac{\partial A}{\partial\theta} u \right] }. \]

在障碍物几何/SDF 反演中，通常右端不随障碍物参数变化，即 \(\partial b/\partial\theta=0\)，因此：

\[ \frac{dL}{d\theta} = - \operatorname{Re} \left[ \lambda^H \frac{\partial A}{\partial\theta} u \right] \]

固定场景的 phase-only 优化已经通过响应基 \(G\) 实现，不需要每轮求解伴随 PDE。上述显式伴随路径用于未来 obstacle/SDF inversion；当前还需要补齐 \(A\) 对 SDF、姿态或材料参数的可微装配。

有限差分验证

当前 src/algorithm/baselines/adjoint/ 在启用 gradient_check 时使用中心差分验证相位梯度：

\[ \frac{\partial L}{\partial\phi_r} \approx \frac{ L(\phi+h e_r)-L(\phi-h e_r) }{2h} \]

配置项：

algorithm: "adjoint"
algorithm_options:
  gradient_check: true
  gradient_check_step: 1.0e-3

验证输出会比较：

  • adjoint_gradient: 解析 VJP 得到的梯度。
  • finite_difference: 中心差分梯度。
  • absolute_error: 绝对误差。
  • relative_error: 相对误差。

当前结论

  • 固定场景相位优化：已具备解析梯度，在线阶段只需要 \(G\)、\(G^H\) 乘法。
  • 梯度验证：通过中心差分比较，能检查符号、共轭和相位链式法则是否正确。
  • 障碍物/SDF 反演：需要 PDE 伴随和可微材料装配，不能复用固定响应基。
