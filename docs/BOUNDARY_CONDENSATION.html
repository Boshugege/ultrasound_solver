边界凝聚：到底优化了什么，怎样优化？

把“已经知道怎么由别的点算出来”的边界声压，先代入其他方程。大型求解器只解剩下的未知量，最后再恢复边界。

最重要的区别：我们优化的是同一个离散声场方程组的求解方式，不是换物理模型、删掉障碍物、忽略边界，也不是在这里优化换能器相位。

当前实现口径：sinc Neumann 声源以及 open、impedance 等 Robin/Neumann 自然边界都保留在保守 PDE 行中，不再按早期“两元素边界行” 递归消元。下文 Schur 补仍说明通用代数原理；生产代码只消去经过结构检查的 Dirichlet 规定值自由度。均匀自由场的 x/y 特征分解与 z 消元是另一种与完整 PDE 等价的内部表面凝聚实现。

1. 原来的求解贵在哪里？

三维空间离散成网格后，每个网格点对应一个复声压未知量。原系统写成 A u = b：A 描述点与点之间的耦合，b 描述激励，u 是要解的完整声场。

直接求解通常分两步：先对 A 做矩阵分解，再用分解结果对 b 做回代。分解不仅需要计算，过程中还可能产生原矩阵没有的非零元素，称为填充，这些分解因子会占用大量内存或显存。

当前保守装配让内部、reflecting、open、impedance 和 sinc Neumann 源面保持 统一的复对称结构；只有 soft 等规定值行需要单独处理。边界凝聚的目标是在不改变 离散问题的前提下消去这类可验证的规定值自由度。

直接处理原系统

所有未知量一起进入大型分解；矩阵包含破坏对称性的边界行。

先做边界凝聚

先代入简单边界关系，再分解更小、经过检查的复对称系统，最后恢复完整声场。

所以有两个优化方向：减少大型分解中的未知量，以及让大型分解能利用复对称结构。它不是只为了省掉几次边界点计算。

2. 哪些点能先处理？不是所有边界点都删除

点的类型声压关系当前处理方式
soft 等规定值点声压由 Dirichlet 条件给定。可从大型系统消去；已知值的影响移入右端。
sinc Neumann 孔径在 reflecting 控制体积上注入通量 RHS。不产生规定值自由度，不参与 Dirichlet 消元。
open / impedance 点局部面通量累加到保守 PDE 行。保留，不按旧式两元素行消元。
普通内部点需要综合相邻点耦合求解。保留，交给大型直接求解器。
刚性反射边界点零外向通量的保守控制体积行。保留；若同时是 soft 规定值点则按 Dirichlet 处理。

文档后面的 E 表示先消去、后恢复的点，R 表示保留并参与大型求解的点。这是按方程结构分组，不是把物理空间挖掉一部分。障碍物材料造成的散射仍然在原方程中。

3. 四个未知量，完整算一遍

用 x、y 代表两个保留点的声压，用 d、e 代表两个将被消去的边界点声压。

以下实数系数只是为了方便手算，不是实际 40 kHz 声场参数；真实求解采用复数，代入规则相同。这里的 x、y 是声压变量名，不是坐标轴。

原始四条方程：
①  4x − y − d = 1       ← x 与相邻点耦合
② −x + 4y − e = 11      ← y 与相邻点耦合
③  d = 3               ← 指定声压，已经知道
④  e = 0.5y + 1        ← 边界声压可由 y 表示
  1. 把已知声压 d 代入第一条
    4x − y − 3 = 1
        4x − y = 4

    d 不再是大型系统的未知量，但它的影响从左边移到了右边，并没有丢失。

  2. 把 e 的表达式代入第二条
    −x + 4y − (0.5y + 1) = 11
             −x + 3.5y = 12

    边界的影响改变了 y 的系数，也改变了右端。注意不是直接把 e 那一项删掉。

  3. 大型求解器只需要解两个未知量
     4x −   y = 4
 −x + 3.5y = 12

解得：x = 2，y = 4
  4. 恢复边界点，再检查原方程
    d = 3
e = 0.5 × 4 + 1 = 3

① 4 × 2 − 4 − 3 = 1       ✓
② −2 + 4 × 4 − 3 = 11     ✓
③ d = 3                    ✓
④ 3 = 0.5 × 4 + 1          ✓

这四步合起来就是边界凝聚求解：先表示边界 → 代入保留方程 → 解缩小系统 → 恢复边界。没有另一套“复杂方法”需要叠加在这套代入方法之外。

4. 更关键的收益：恢复复对称结构

还是刚才的例子。按 [x, y, d, e] 排列，原矩阵为：

       x     y     d     e
  x [  4    −1    −1     0  ]
  y [ −1     4     0    −1  ]
  d [  0     0     1     0  ]
  e [  0   −0.5    0     1  ]

x 的方程含 d，系数是 −1；但 d 的方程不含 x，系数是 0。y 与 e 的耦合系数也分别是 −1 和 −0.5。交换行列后矩阵不同，所以原矩阵不对称。

消去 d、e 后，只剩：

        x     y
  x [   4    −1  ]
  y [  −1    3.5 ]

现在 x 与 y 的耦合系数都是 −1，剩余矩阵对称。我们实际的离散系统也是利用这种结构，只是系数可以是复数。

“复对称”具体意味着什么？

矩阵两侧对应元素直接相等，即 Sᵀ = S。它不要求取共轭，因而不是 Sᴴ = S 的 Hermitian 矩阵，也不意味着正定，不能据此直接当作实数正定系统做 Cholesky。

代码如何利用这个结构？

  • 先构造实际的约化矩阵 S，计算 max|S − Sᵀ| / max|S|；默认容差为 1e-12，不通过就报错。
  • 通过后只把 S 的下三角交给 cuDSS，并明确设置 SYMMETRIC 和 LOWER。
  • 求解器据此使用对称结构进行分析和分解，而不是把对应的上下三角当成两份独立数据处理。

这不等于总内存减半。原矩阵、边界子块、CPU 边界 LU、排序与分解填充、GPU/CPU 工作区仍然存在。实际时间和峰值内存必须测量。

5. “依赖链”和“凝聚”是什么关系？

在面中央，向内一步可能就是保留点；在棱边或角点，向内一步后可能仍在另一个开放面上。于是边界点依赖另一个边界点：

角点 e → 另一个边界点 q → 最终保留点 r

uₑ = 2u_q + 1
u_q = 3u_r + 4

代入：uₑ = 2(3u_r + 4) + 1 = 6u_r + 9

这一步只回答“边界怎样由保留点表示”，还没有求出 u_r。接下来要把 uₑ = 6u_r + 9 代入那些含 uₑ 的保留方程，才形成缩小后的可求解系统。

图中抽象公式 uₑ = γₑγ_q u_r + γₑδ_q + δₑ 就是上面“2 乘 3”和“2 乘 4 再加 1”的通用写法。γ 是乘数，δ 是已知项，真实声学问题中它们可以是复数。

当前每个开放边界行只有一个向内邻居，所以一个被消去点沿链最终最多关联一个保留点。如果链终止于指定声压点，则不再依赖任何保留未知量。这使依赖关系可以存成很稀疏的传递矩阵 T。

不是说整个声场矩阵每行只有一个非零元，也不是说所有 Schur 补都不会变稠密。这里只利用了当前边界离散的特殊结构；代码也会检查依赖是否成环。

6. 代码实际上做了哪些工作？

场景固定时，先做一次

  1. 装配完整 A，识别保留点 R 和消去点 E。
  2. 沿依赖链构造 T：记录各边界点最终依赖谁、乘多少。
  3. 把关系代入保留方程，得到 S，并检查复对称性。
  4. 用 SciPy splu 分解边界块 AEE。
  5. 让 cuDSS 分解约化系统 S。

每来一个新的激励 b

  1. 用边界 LU 求出这次激励的边界已知项。
  2. 修正保留方程的右端。
  3. 复用 S 的因子，解出保留点声压。
  4. 通过已知项与 T 恢复全部边界点。
  5. 还原原网格顺序，并检查完整系统残差。

公式里出现 AEE−1，不代表程序创建了一个稠密逆矩阵。程序用递归依赖构造齐次传递 T，用边界稀疏 LU 处理随 RHS 变化的已知项。CPU 边界分解并没有被省掉。

它与响应基、相位优化的关系

边界凝聚 + 分解→逐阵元回代，建立 G→在线 u = G exp(iφ)

边界凝聚主要作用于大型 PDE 求解及响应基构建阶段。响应基 G 已经建立后，当前相位优化内环直接做 G 和 Gᴴ 的矩阵运算，不在每次 Adam 更新中再执行凝聚或 PDE 分解。

“一次分解、多次回代”是固定矩阵直接法本身也能使用的策略，不是凝聚独有的发明。凝聚让这份被反复复用的大型分解更小、具有可利用的对称结构。

7. 能省多少？不能优化什么？

点数变少，不等于体积问题变成表面问题

举一个纯几何计数例子：假设 n × n × n 网格的外壳全部消去，且没有额外内部指定点，则保留 (n − 2)³ 个未知量。

示意网格原未知量保留未知量消去比例
41³68,92159,319约 13.9%
121³1,771,5611,685,159约 4.9%

这里只是“整个外壳被消去”的算术例子，不是当前含反射面的实际配置统计，更不是性能测量。实际消去哪些点以 _eliminated_mask() 为准。

网格越大，边界点占比通常越低。我们仍然要解一个大型三维内部系统，因此更重要的收益还要看复对称结构、分解填充和后端策略。

能改善或利用不能由此推出
减少进入大型分解的自由度。不能保证未知量减少一半，更不等于耗时按点数等比例下降。
使用 S 的复对称结构和下三角输入。不能保证整体内存减半，也不会消除内部因子填充。
固定场景复用分解因子。几何、材料、网格、频率或边界改变后不能继续复用旧分解。
等价重排离散方程的求解过程。不会提高每波长网格点数，不能修复数值色散或不准确的开放边界模型。
提供完整复声压，支持伴随求解。不会直接优化 loss、改变相位量化精度或完成硬件标定。

也有新增开销：提取子块、解析依赖链、构造和检查 S、边界 LU 以及每次边界回代。小问题上这些开销可能抵消收益。高分辨率能否装入内存，应查看 cuDSS 预分析，不能仅凭“用了凝聚”判断。

8. 再看矩阵公式：只是把代入写成批量操作

读到这里再看符号：u_R 是所有保留点声压组成的向量，u_E 是所有被消去点声压组成的向量。ARE 表示“保留方程中，边界未知量前面的系数”。下标第一个字母是方程行，第二个是变量列。

保留方程：A_RR u_R + A_RE u_E = b_R
边界方程：A_ER u_R + A_EE u_E = b_E

先表示边界：u_E = c_E + T u_R
其中：
  T   = −A_EE⁻¹ A_ER       ← 谁依赖谁、乘多少；与这次激励无关
  c_E =  A_EE⁻¹ b_E        ← 这次激励带来的已知项

代入保留方程：

(ARR+ARET)uR=bR−AREcE

把左边括号记为 S，就得到了 PPT 中的 Schur 补：

S=ARR−AREAEE−1AER

Schur 补不是额外的神秘求解器。它就是“把边界关系代入后，内部方程的新系数矩阵”。

历史说明：早期两元素 open 行为何不再使用？

早期一阶 Sommerfeld 离散曾写为：

(1/h − i k₀) u_e − (1/h) u_q = b_e

整理：
u_e = [1 / (1 − i k₀h)] u_q + b_e / (1/h − i k₀)

这种整行替换会丢弃原 PDE 的其他切向通量，并且在棱角只能选择一个面。 当前实现改为把局部 iω/(ρc) 或 iω/Z 面通量累加到 原控制体积行；Robin/Neumann 点因此保留在大型系统中。

当前规定值行仅来自 soft 等 Dirichlet 条件；阵元使用 sinc Neumann 通量， 不再是 u_e=P₀exp(iφ)。

补充：为什么凝聚前后解相同？

若 AEE 可逆，边界方程与 u_E = c_E + Tu_R 完全等价。把它代入保留方程，没有删掉任何约束。反过来，解出约化系统并恢复 uE 后，两组原方程都满足。

前面的四元例子已经逐条验证了这一点。严格等价指的是代数上的离散方程；浮点计算仍有舍入误差，实际还需看完整系统残差。小残差也不能证明连续 PDE 已充分网格收敛，病态系统还需关注误差放大。

补充：为什么伴随可以复用同一份大型因子？

伴随方程是 Aᴴλ = q。按相同分块消元，得到：

d_E = A_EE⁻ᴴ q_E
r_R = q_R − A_ERᴴ d_E
Sᴴ λ_R = r_R

S 复对称，即 Sᵀ=S，所以 Sᴴ=conj(S)。因此：

λ_R = conj(solve(S, conj(r_R)))
λ_E = solve(A_EEᴴ, q_E − A_REᴴ λ_R)

对右端取共轭，用已有 S 因子求解，再对结果取共轭，就不必为 Sᴴ 额外保存大型因子。边界部分复用 SciPy LU 的 trans="H" 回代。当前响应基优化内环直接使用 Gᴴ，这个伴随接口并不意味着每步 Adam 都重新求 Aᴴλ=q。

9. 如何确认结果没变、性能有提升？

先确认解的是同一组方程

  • 选一个可直接分解的小网格，对同一个 A、同一个 b，比较完整直接解与凝聚后恢复的完整 u。
  • 计算完整系统残差 ‖Au − b‖ / ‖b‖，不是只检查内部点；当 b=0 时应看绝对残差，避免零分母。
  • 对伴随也比较 Aᴴλ=q 的解和完整残差；核对 relative_symmetry_error。
  • 需要检查浮点误差与条件数影响；物理准确性另做网格收敛、COMSOL 或实测验证。

再分别测建模阶段与重复求解阶段

需要回答的问题当前可查看的统计解释
少了多少大型未知量？dofs、reduced_dofs、eliminated_boundary_dofs这是结构计数，不是加速比。
凝聚增加多少准备时间？condensation_seconds、boundary_factor_seconds应计入首次场景准备时间。

重复激励求解多快？solve_seconds、solve_count、boundary_solve_seconds外层 solve 时间已包含相应边界处理，不能把边界时间再次相加。
资源预算够不够？memory_estimates 中设备/主机峰值预估这是后端预估，不等于进程整体实测峰值；完整比较还需实测。

本页没有给出固定加速倍数。相位优化中 Adam 与 L-SHADE 的达标时间比较，不能拿来当作边界凝聚的性能实验；它们测的是不同层面的算法。

适用条件与失败保护

当前指定值点必须来自可验证的 Dirichlet 单位行；递归依赖必须无环， AEE 必须可解，S 必须通过复对称检查。sinc Neumann 孔径仅改变 RHS， 不应被标记为待消去的规定值点。

高阶多邻居开放边界、PML 或其他离散方式不自动满足旧式局部边界递归条件， 必须按当前保守矩阵结构重新分析，不能跳过保护检查强行套用。
