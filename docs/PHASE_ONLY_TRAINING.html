Fixed-Scene Phase Optimization with a Full-Field Response Basis

本文档只描述当前已实现的固定场景 phase-only 优化。 当前源矩阵来自 sinc Neumann 有限孔径通量； 响应基由 Helmholtz 求解器离线构建，随后作为在线优化的精确缓存层。

优化变量仅为 M 个换能器相位。障碍物、材料、边界、频率、阵元位置和阵元幅值在一次优化期间保持不变；改变其中任一项都必须重新构建响应基。

相位相关右端

固定网格、材料、障碍物、频率、边界条件和阵元位置后，Helmholtz 矩阵 \(A\) 不依赖相位：

\[ A u(\phi)=b(\phi) \]

设共有 \(M\) 个换能器。定义：

\[ w(\phi) = \begin{bmatrix} e^{i\phi_1} \\ e^{i\phi_2} \\ \vdots \\ e^{i\phi_M} \end{bmatrix} \]

定义源矩阵 \(B\in\mathbb{C}^{N\times M}\)。第 \(r\) 列是第 \(r\) 个阵元 归一化 sinc Neumann 孔径经求积、双线性沉积和有限体积缩放后形成的稀疏 RHS， 再乘固定阵元幅值 \(A_r\)；归一化孔径质量为 1。于是：

\[ b(\phi)=Bw(\phi) \]

全场响应基

将源矩阵的每一列通过同一个 Helmholtz 系统求解：

\[ G=A^{-1}B \]

其中：

\[ G = \begin{bmatrix} g_1 & g_2 & \cdots & g_M \end{bmatrix} \]

\(g_r\) 是第 \(r\) 个阵元独立激励时，在完整网格、完整障碍物和全部边界条件下产生的全空间复声场。

利用线性性：

\[ u(\phi) = A^{-1}Bw(\phi) = Gw(\phi) \]

因此在线阶段不再求解 PDE，只执行一次复数矩阵向量乘法。

为什么仍是完整精确声场

响应基不是自由空间传播近似，也不是只保留目标点。矩阵 \(G\) 的行数等于全部体素自由度：

\[ G\in\mathbb{C}^{N_{\mathrm{voxel}}\times M} \]

每列通过当前离散系统直接求得，所以自动包含：

  • 变密度与变声速材料。
  • 障碍物散射。
  • Reflecting 边界。
  • Open Sommerfeld 边界。
  • 归一化 sinc Neumann 有限孔径通量。

其误差只来自构建 \(G\) 时的直接求解残差和浮点误差，不额外引入物理近似。

相位梯度与 VJP

对于第 \(r\) 个相位：

\[ \frac{\partial w_r}{\partial\phi_r} = i e^{i\phi_r} \]

因此：

\[ \frac{\partial u}{\partial\phi_r} = i g_r e^{i\phi_r} \]

设实值损失 \(L\) 对复声场的 cotangent 为 \(c\)，采用：

\[ dL = \operatorname{Re} \left( c^Hdu \right) \]

则：

\[ \frac{\partial L}{\partial\phi_r} = \operatorname{Re} \left[ \left( c^Hg_r \right) i e^{i\phi_r} \right] \]

先计算一次：

\[ z=G^Hc \]

即可得到全部相位梯度：

\[ \nabla_\phi L = \operatorname{Re} \left[ \overline z \odot \left( i e^{i\phi} \right) \right] \]

PhaseResponseBasis.phase_vjp() 实现该解析 VJP，不需要在线 PDE 伴随求解。

离线构建流程

  1. 装配一次固定矩阵 \(A\)。
  2. 执行一次边界凝聚和 cuDSS factorization。
  3. 按阵元批次构造 \(B\) 的列。
  4. 复用同一因子求解每批 RHS。
  5. 把结果列写入磁盘 .npy memmap。
  6. 每批完成后更新 JSON 元数据中的完成列数。
  7. 全部完成后可释放 cuDSS 因子。

当前 cuDSS HMM wrapper 对矩阵 RHS 逐列回代，因此只建立一次因子，但仍执行 \(M\) 次三角回代。

断点恢复与缓存一致性

响应基文件旁保存：

phase_response_basis.npy
phase_response_basis.npy.json

元数据包含：

  • 格式版本。
  • 矩阵形状。
  • 固定 complex128 数据类型。
  • 已经完成的阵元列数。
  • 物理场景 SHA-256 指纹。

每完成一个 RHS 批次，先刷新 memmap，再原子替换元数据文件。进程中断后，从最后完成的列继续构建。

场景指纹覆盖：

  • 背景物理参数。
  • 换能器规格和幅值。
  • 网格与物理尺寸。
  • 边界条件。
  • 障碍物配置。

指纹不匹配时拒绝加载，避免把旧场景的响应基用于新矩阵。

内存与计算量

响应基的存储量随网格自由度 \(N\) 和阵元数 \(M\) 线性增长。当前公开算法对比使用 \(41^3\) 网格和 \(12\times12=144\) 个阵元：

\[ N=41^3=68{,}921 \] \[ M=144 \]

complex128 响应基大小为：

\[ NM\times16 = 158{,}793{,}984\ \mathrm{bytes} \approx 151.4\ \mathrm{MiB} \]

完整复声场本身约为：

\[ N\times16 \approx 1.05\ \mathrm{MiB} \]

高分辨率验证会迅速放大这项成本：例如在同一物理域由 \(41^3\) 提升到 \(121^3\)，响应基仅存储量约增至 4 GiB。当前策略是低分辨率搜索相位、高分辨率复算或 warm-start 精修，而不是将低分辨率结果直接视为物理解。

CPU 与 GPU 在线路径

GPU 常驻

\[ u=G_{\mathrm{GPU}}w \] \[ z=G_{\mathrm{GPU}}^Hc \]

适用于频繁迭代。加载前会检查空闲显存，并预留 256 MiB 安全空间。

CPU memmap

如果不加载到 GPU，则按体素块执行：

\[ u_{s:e} = G_{s:e,:}w \]

VJP 同样按块累加：

\[ z = \sum_{\mathrm{chunk}} G_{\mathrm{chunk}}^H c_{\mathrm{chunk}} \]

这种方式显存要求更低，但会受磁盘和主存带宽限制。

配置

mode: "phase_optimization"
algorithm: "adjoint"
algorithm_options:
  optimizer: "adam"
  learning_rate: 0.05
  gradient_check: true
  gradient_check_step: 1.0e-3

training:
  phase_basis_file: "phase_response_basis.npy"
  phase_basis_batch_size: 8
  voxel_chunk_size: 262144
  load_basis_to_gpu: true
  release_factor_after_basis: true

solver:
  backend: "cudss_hybrid_direct"

phase_optimization 当前要求 cudss_hybrid_direct，以便在构建响应基时复用同一份直接分解因子；GPU 常驻响应基适合频繁优化迭代。

Python 接口

solver = HelmholtzDirectSolver(cfg)
basis = solver.build_phase_response_basis()

# 可选：将当前响应基加载到 GPU
basis.to_gpu()

field = basis.field(phases)
phase_gradient = basis.phase_vjp(field_cotangent, phases)

相位响应基只能跨相位迭代复用，不能跨障碍物、材料、频率、网格、边界条件或阵元几何变化复用。优化这些场景参数属于不同问题，不在当前训练接口范围内。
