
## 结果

原水平板、旋转板、位置偏移板三组均得到接近真实几何的候选解。
但每组三个固定初值中都只有一个恢复良好，另外两个停在错误解；当前不能保证全局稳定恢复。
**三维图统一以蓝色半透明板体及实线表示真实板，以红色虚线轮廓和顶点表示反演结果，二者按真实坐标叠加。**

## 实验设定与信息边界

| 项目 | 统一设置 |
|---|---|
| 发射 | 3×3 阵列，40 kHz，全通道相位 0 rad、幅度 1，作为已知量 |
| 可用观测 | −x、+x、−y、+y、+z 五个物理边界面，16×16 点/面，共 1,280 点；只有振幅 |
| 边界条件 | 五面开放辐射，外接 6 mm PML；底面有源刚性挡板 |
| 物理区域 | x/y = 6…42 mm，z = 0…42 mm |
| 介质 | 空气与已知均匀板材，声学流体等效；不包含固体剪切波 |
| 几何先验 | 单块正三角柱；未知中心 3 参数、旋转 3 参数、边长和厚度，共 8 参数 |
| 生成 / 反演 | 均为 49³ 网格，无观测噪声；界面平滑半宽 0.8 mm |
| 优化 | PDE 正向 + 离散伴随梯度，L-BFGS-B；三个固定初值，每初值最多 60 次迭代 |
| 选择规则 | 只按五面振幅损失选最佳候选；真值仅用于观测生成和事后几何评价 |

唯一优化目标为：

```text
L = (1/5) Σ五个面 [Σ该面 (|p预测| − a观测)² / Σ该面 a观测²]
报告中的振幅相对 RMS = sqrt(L)，以百分比显示。
```

没有测量相位、内部声场或几何真值损失。这里已知“正三角板”类别；
未知的是尺寸与位姿，尚不是任意未知拓扑的空气/板材分割。

| 场景 | 真实中心 mm | 真实 xyz 外禀 Euler 角 | 边长 / 厚度 |
|---|---|---|---|
| 原水平板 | (25,23,23.5) | (0,0,0)° | 18 / 3 mm |
| 旋转板 | (25,23,23.5) | (12,−8,15)°，绕质心旋转 | 18 / 3 mm |
| 偏移板 | (27,26,21.5) | (0,0,0)°；平移 (+2,+3,−2) mm | 18 / 3 mm |

## 结论与适用范围

1. 在已知三角板类别、固定同相发射和仅五面振幅的条件下，当前方法已在水平、旋转和偏移三个场景得到接近真值的恢复。
2. 同网格无噪声实验验证离散模型的自洽性。旋转组非常小的误差不能解释为现实系统可达到的测量精度。
3. 初值敏感性仍然明显。原实验的 65³→49³ 跨网格测试振幅 RMS 为 8.41%、IoU 为 75.41%，表明模型离散误差同样重要。
4. 后续应先检查网格/界面/PML 收敛，改进仅依赖五面振幅的初始化，再评估观测噪声与发射/接收标定误差。
